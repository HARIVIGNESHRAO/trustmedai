# TrustMedAI Hyperledger Fabric network

This is a local development network with two peer organizations (`Org1MSP` and `Org2MSP`) and a Raft ordering service. It is a real permissioned Fabric ledger, but both organizations run on one computer for development.

Only a SHA-256 report proof, model version, timestamp, transaction ID, and status are written on-chain. Medical reports, identity, biomarkers, and predictions remain in PostgreSQL.

Start Docker Desktop, then run:

```bash
./start-local-network.sh
```

Stop and remove local ledger containers and development identities:

```bash
./stop-local-network.sh
```

The Spring service expects the local Org1 application identity generated by the test network. Configure `FABRIC_ENABLED=true` after the network is started.
